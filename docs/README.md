# StreamVault

StreamVault is a Windows media player for local video collections. It includes a personal library, saved playback progress, Watch Party rooms, chat, subtitle support, and HandBrake-powered encoding tools.

## Download

[Download StreamVault for Windows](https://github.com/Folodkam/Streamvault-/releases/download/VideoPlayer/StreamVault-Setup-1.5.0.exe)

## What You Can Do

- Build a local media library from folders on your computer.
- Resume videos and keep track of watch progress.
- Load subtitles and control playback in a focused desktop player.
- Create or join Watch Party rooms with synced play, pause, seek, chat, and reactions.
- Import HandBrake presets and queue video encoding jobs.

## Quick Start

1. Install StreamVault on Windows.
2. Add a media folder in the Library screen.
3. Open a video from your library.
4. Start a Watch Party when you want friends to watch in sync.
5. Use the Encoder screen when you want to convert media with HandBrake presets.

## Watch Party

Watch Party rooms help friends stay synced while watching together. Share the invite details from StreamVault, then use the room chat, reactions, and shared playback controls during the session.

For best results, everyone should have the same media file or a matching copy.

## Privacy

StreamVault is designed around local media files. Your library is managed on your computer, and the app is meant for media you own or have permission to watch.
